오르락(이하 "앱")은 클라이밍 영상에서 등반 시도를 잘라 클립으로 저장하고, 다녀온 암장과 등반 기록을 남기는 앱입니다. 영상 분석은 모두 기기 안에서 합니다. 이 문서는 앱이 어떤 정보를 어디에 저장하고 보내는지 설명합니다. 문의는 맨 아래 이메일로 받습니다.

이전 처리방침(2026-10-27 시행)과 달라진 점: ① 위치정보 항목(위치 이용 동의, 위치 이용 기록 6개월 보관, 동의 철회) 추가, 암장 검색에 현재 위치를 보내지 않음, 영상 요약에서 암장 제거 ② 빠져 있던 수집 항목(의견, Apple 로그인 토큰, 등반 기록의 촬영 일시)과 Slack 전송 추가, 사용 통계가 계정 식별자와 연결된다는 사실을 바로잡음 ③ 국외 이전 항목(근거·국가·연락처), 파기 절차·방법, 자동 수집 장치와 거부 방법, 로그인하지 않은 사용자의 삭제 방법 추가

저장하는 것

계정 정보, 방문·등반 기록, 영상 요약. 원본 영상은 올리지 않고, 클립은 백업에 동의했을 때만 줄인 사본을 저장해요. 위치 좌표는 저장하지 않아요.

5보관과 파기

  • 계정에 저장한 정보(백업한 클립 포함)는 계정을 삭제할 때까지 보관합니다. 클립 하나를 지우고 싶으면 맨 아래 이메일로 요청할 수 있습니다.
  • 로그인하지 않은 익명 식별자의 기록(백업한 클립 포함)은 마지막 사용 후 1년이 지나면 삭제합니다.
  • 회원 탈퇴: 앱 설정 → 계정 → 회원 탈퇴. 계정과 서버에 저장된 모든 정보(방문 기록, 도감 사진, 등반 기록, 백업한 클립, 영상 요약, 투표·제보, 의견, 알림 설정, 위치 동의·이용 기록)를 지웁니다. 로그아웃은 정보를 삭제하지 않습니다.
  • 로그인하지 않은 사용자: 개인정보·위치 요청 페이지(앱 [설정 → 앱 정보 → 개인정보·위치 요청])에서 "서버에 저장된 내 기록 삭제"를 요청하면 같은 범위를 늦어도 10일 안에 지웁니다. 사용자 ID는 앱에서 열면 자동으로 채워지고, 이메일로 요청할 때는 앱 정보에 보이는 사용자 ID 앞 8자리를 알려 주세요.
  • 파기 절차와 방법: 삭제 요청·탈퇴·보유기간 만료 시 데이터베이스의 해당 행을 지웁니다(복구할 수 없음). 백업 클립 파일은 삭제 대기열에 넣어 보통 몇 분 안에 저장소에서 지웁니다. 위치 이용 기록은 6개월이 지나면 매일 자동으로 지웁니다. 별도의 데이터베이스 백업 사본은 보관하지 않으며, 백업을 두게 되면 보관 기간을 이 페이지에 먼저 알립니다.
  • 오류 기록은 Sentry에서 30일, 사용 통계는 PostHog에서 1년 보관한 뒤 자동으로 지워집니다.
