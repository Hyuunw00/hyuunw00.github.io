오르락(이하 "앱")는 클라이밍 영상에서 등반 시도를 잘라 클립으로 저장하고, 다녀온 암장과 등반 기록을 남기는 앱입니다. 영상 분석은 모두 기기 안에서 합니다. 이 문서는 앱이 어떤 정보를 어디에 저장하고 보내는지 설명합니다. 문의는 맨 아래 이메일로 받습니다.

저장하는 것

계정 정보, 방문·등반 기록, 영상 요약. 원본 영상은 올리지 않고, 클립은 백업에 동의했을 때만 줄인 사본을 저장해요.

보관 기간

계정은 탈퇴할 때까지, 로그인 안 한 기록은 마지막 사용 후 1년.

삭제 방법

앱 설정 → 계정 → 회원 탈퇴. 즉시 전부 삭제돼요.

1서버에 저장하는 정보

앱을 처음 열면 기기마다 임의의 익명 식별자가 만들어지고, 등반 기록·영상 요약·클립 백업·암장 제보·난이도 신고는 로그인하지 않아도 이 식별자로 서버에 저장됩니다. 로그인하면 같은 계정으로 합쳐집니다. 방문 등록, 도감 사진, 난이도 순서 입력과 투표는 로그인한 계정에서만 저장됩니다.

용도운동 날 알림 보내기

원본 영상은 서버에 올리지 않습니다. 잘라낸 클립은 "클립 백업"에 동의했을 때만 줄인 사본을 서버에 저장하고, 앱 설정에서 언제든 끌 수 있습니다(끄면 그 뒤로 저장하는 클립은 올리지 않습니다). 백업한 클립은 본인만 볼 수 있고 다른 사용자에게 공개하지 않습니다. 다른 사용자에게 보여 주는 기능을 만들 때는 따로 동의를 받고, 클립에 함께 찍힌 사람의 요청이 있으면 그 클립을 지웁니다.

영상의 촬영 위치는 기기에서 근처 암장을 찾는 데 쓰고, 서버에는 좌표가 아니라 암장 식별자만 남습니다. 로그인과 서버 요청 때 접속 IP가 서버 보안 기록에 남고 짧은 기간 뒤 자동으로 지워집니다.

2오류 기록과 사용 통계

앱을 고치고 개선하기 위해 아래 정보를 외부 서비스로 보냅니다. 영상, 사진, 위치 좌표, 이메일, 이름은 보내지 않습니다.

오류 기록 · Sentry

앱이 멈추거나 오류가 났을 때의 오류 내용, 오류가 난 화면 이름, 기기 모델, OS·앱 버전, 익명 식별자, 접속 IP

용도오류 원인 찾기

사용 통계 · PostHog

앱 실행, 영상 고름(개수), 분석 완료, 클립 저장, 도감 등록, 난이도 투표 같은 사용 단계와 시각, 기기 모델, OS·앱 버전, 언어·시간대 설정, 화면 크기, 익명 식별자

용도어떤 기능이 쓰이는지, 어디서 막히는지 파악

이 익명 식별자는 각 서비스가 기기마다 만든 임의의 값으로, 계정 이메일이나 이름과 연결하지 않습니다. 끄기 설정은 따로 없으며, 보내지 않으려면 앱을 사용하지 않는 방법밖에 없습니다.

이와 별도로, 안드로이드에서 보조 분석 엔진(MediaPipe Tasks)이 동작할 때 그 라이브러리가 성능·사용 지표(처리 시간, 호출 횟수, 라이브러리 버전 등)를 Google LLC로 직접 보냅니다. 앱이 맡긴 것이 아니라 라이브러리 자체의 수집이며, 영상 내용은 포함되지 않습니다(구글 개인정보처리방침).

4보관과 삭제

  • 계정에 저장한 정보(백업한 클립 포함)는 계정을 삭제할 때까지 보관합니다. 클립 하나를 지우고 싶으면 맨 아래 이메일로 요청할 수 있습니다.
  • 로그인하지 않은 익명 식별자의 기록(백업한 클립 포함)은 마지막 사용 후 1년이 지나면 삭제합니다.
  • 앱 설정 → 계정 → 회원 탈퇴를 누르면 계정과 서버에 저장된 모든 정보(방문 기록, 도감 사진, 등반 기록, 백업한 클립, 영상 요약, 투표·제보, 알림 설정)가 즉시 삭제됩니다. 로그아웃은 정보를 삭제하지 않습니다.
  • 오류 기록은 Sentry에서 30일, 사용 통계는 PostHog에서 1년 보관한 뒤 자동으로 지워집니다. 이 기록은 계정과 연결되지 않아 개별 삭제 요청은 받지 않습니다.

자세한 절차: 계정 및 데이터 삭제 안내

5정보주체의 권리와 안전 조치

  • 열람·정정·삭제·처리 정지는 앱 안에서 직접 하거나(기록 수정·삭제, 회원 탈퇴) 맨 아래 이메일로 요청할 수 있고, 요청은 10일 안에 처리합니다. 만 14세 미만은 이용할 수 없으므로 법정대리인 절차는 없습니다.
  • 안전 조치: 모든 서버 통신은 암호화(HTTPS)되고, 서버 데이터는 계정별 접근 권한 규칙으로 본인만 읽고 쓸 수 있습니다. 클립 저장소는 공개 접근이 막혀 있고, 본인 계정에 짧은 시간만 쓸 수 있는 주소를 발급해서 올리고 받습니다. 운영자는 서비스 운영에 필요한 범위에서만 접근합니다.
  • 권익 침해 상담·신고: 개인정보침해신고센터(privacy.kisa.or.kr, 국번 없이 118), 개인정보분쟁조정위원회(kopico.go.kr, 1833-6972), 대검찰청(spo.go.kr, 1301), 경찰청(ecrm.police.go.kr, 182)
